# NL Lanka Travel & Tours (demo)

    npm install
    npm run dev      # local preview at http://localhost:5173
    npm run build    # production build in /dist

Deploy on Vercel: import the repo, framework "Vite", build command `npm run build`, output `dist`.

Edit content (phone, prices, tours, reviews) in `src/data.js`.
Photos live in `public/images/` (replace with the client's own, keep the file names).
